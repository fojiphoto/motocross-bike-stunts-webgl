# Moto Dirt Flake 3D - WebGL

Play: https://fojiphoto.github.io/motocross-bike-stunts-webgl/

This repository only holds the built WebGL game (no source). It is produced by
`Tools/WebGL/6. Build WebGL` in the private game project (branch
`Motocross_Bike_Stunt_WebGL`) and copied here as-is.

Controls: arrows or WASD to drive and lean, Space to brake, or the on-screen buttons.
